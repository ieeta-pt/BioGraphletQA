# 6. Task-Specific Rephrasing & Downstream Evaluation

This directory contains the code for the final part of our experimental pipeline: adapting a subset of BioGraphletQA for specific downstream tasks and evaluating its impact on model performance. 

The workflow involves rephrasing our open-ended QA pairs into the formats required by two popular biomedical benchmarks—**MedQA** and **PubMedQA**—and then running fine-tuning experiments using BioLinkBERT.

---

## MedQA Rephrasing and Conversion

This section covers the process of adapting 20,000 QA pairs to the multiple-choice format of the MedQA dataset.

* **`1_qa_rephrasing_MedQA.py`**: This script takes a subset of the BioGraphletQA dataset and prompts an LLM to rephrase each entry. The prompt includes the original question, answer, and retrieved supporting snippets, along with relevant examples from the actual MedQA dataset to guide the LLM in generating the correct multiple-choice style.
* **`1_run_MedQA.sh`**: An example Slurm batch script to execute the MedQA rephrasing on an HPC cluster.
* **`2_medqa_converter.ipynb`**: A Jupyter notebook used for post-processing. It converts the LLM's rephrased output into the final JSONL format required for training and creates the necessary dataset splits for the experiments.

---

## PubMedQA Rephrasing and Conversion

This section covers the process of adapting QA pairs to the "yes/no/maybe" format of the PubMedQA dataset.

* **`3_qa_rephrasing_PubMedQA.py`**: Similar to the MedQA script, this prompts an LLM to convert our QA pairs into the PubMedQA format, using examples from the target dataset to ensure stylistic consistency.
* **`3_run_PubMedQA.sh`**: An example Slurm batch script for running the PubMedQA rephrasing.
* **`4_pubmedqa_converter.ipynb`**: A Jupyter notebook that converts the rephrased outputs into the final format and prepares the dataset splits for the PubMedQA experiments.

---

## Fine-tuning Experiments and Analysis

These files are used to run the downstream fine-tuning tasks and analyze the results.

* **`5_run_experiments_medqa.sh`**: The main experiment script for MedQA. It fine-tunes the **BioLinkBERT** model on various training set sizes, both with and without augmentation from our rephrased BioGraphletQA data.
* **`6_run_experiments_pubmedqa.sh`**: The main experiment script for PubMedQA, following the same procedure as the MedQA script.
* **`7_results_analysis_v2.ipynb`**: A Jupyter notebook used to parse the log files generated by the experiment scripts. It calculates the final accuracy metrics, computes means and standard deviations across different random seeds, and generates the result plots presented in our paper.
